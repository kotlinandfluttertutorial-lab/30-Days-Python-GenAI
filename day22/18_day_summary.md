# Day 22 — Day Summary: RAG Evaluation

## What You Covered
RAG metrics (faithfulness, relevance, precision, recall), RAGAS framework, custom LLM-as-judge evaluation, evaluation dataset creation, full evaluation pipeline.

## Key Takeaways
1. RAG evaluation needs multiple metrics — no single number captures quality
2. Faithfulness is most critical: hallucination is worse than being off-topic
3. LLM-as-judge is powerful but needs calibration against human annotations
4. Auto-generate eval dataset from documents when you lack labeled test data
5. Track all metrics over time — detect regressions before users report them
