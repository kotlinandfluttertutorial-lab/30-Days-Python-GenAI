# Day 01 — Learning Objectives
## AI Engineer Foundation

---

## What You Will Accomplish Today

By the end of Day 1, you will be able to:

### Knowledge Objectives

1. **Define every core AI term** without hesitation — AI, ML, DL, GenAI, LLM, RAG, Agent, Embedding, Vector Database, Transformer, NLP
2. **Explain the difference** between AI Engineer, ML Engineer, Data Scientist, and Data Engineer roles
3. **Map the complete AI engineering stack** from data to deployed system
4. **Explain what an LLM actually is** — not just "it's like ChatGPT"
5. **Understand what RAG is** and why it exists at a conceptual level
6. **Understand what an AI Agent is** at a conceptual level
7. **Explain the role of Docker, APIs, and Cloud** in AI systems
8. **Understand the difference** between traditional software and AI software

### Skill Objectives

1. **Set up a complete Python AI engineering environment**
2. **Create a virtual environment and install packages**
3. **Write type-hinted Python functions**
4. **Call an LLM API** (or understand the exact code to do so)
5. **Build a CLI tool** that demonstrates AI system knowledge

### Project Objective

Build the **AI Engineer CLI Profile** — a command-line application that:
- Displays a structured AI Engineer knowledge map
- Demonstrates understanding of key AI concepts
- Runs from the terminal
- Uses clean, production-quality Python

## Why This Day Matters

Day 1 sets your mental model for the entire 30 days.

Every day from Day 2 to Day 30 will reference concepts introduced today. If you do not understand the landscape, you will get lost in the details.

The most common mistake engineers make when learning AI: they dive straight into code without understanding what problem each technology solves.

Today fixes that.

## Key Concepts Preview

| Concept | One-Line Summary |
|---------|-----------------|
| AI | Systems that mimic intelligent behavior |
| ML | Learning patterns from data |
| Deep Learning | ML using neural networks |
| LLM | Large language model — predicts next tokens |
| GenAI | AI that generates new content |
| Transformer | Architecture that powers modern LLMs |
| Embedding | Number representation of meaning |
| Vector DB | Database optimized for similarity search |
| RAG | Retrieval-Augmented Generation |
| Agent | LLM + tools + memory + planning |
| API | Interface for calling services |
| Docker | Container for reproducible deployments |
| Cloud | Remote compute and storage |
| LLMOps | Operations for LLM-powered systems |
