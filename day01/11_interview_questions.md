# Day 01 — Interview Questions
## AI Engineer Foundation

---

## How to Use This File

Read each question. Close the document. Answer out loud (not in your head — out loud).  
Then check `12_interview_answers.md`.

Time your answers:
- Short answer: 30 seconds
- Detailed answer: 2 minutes
- System design: 5-10 minutes

---

## Tier 1: Recruiter / Screening Round

These questions appear in phone screens and recruiter calls.

**Q1.** What is a Large Language Model?

**Q2.** What is RAG and why is it important?

**Q3.** What is the difference between an AI Engineer and a Machine Learning Engineer?

**Q4.** What does the context window mean for an LLM?

**Q5.** What is prompt engineering?

**Q6.** Why do LLMs hallucinate?

**Q7.** What is an AI Agent?

**Q8.** What is an embedding?

---

## Tier 2: Technical Round

These questions appear in technical interviews with engineers.

**Q9.** Explain the Transformer architecture. What problem did it solve that RNNs couldn't?

**Q10.** How does RAG work end-to-end? Walk me through the complete pipeline.

**Q11.** What is the difference between RAG and fine-tuning? When would you choose each?

**Q12.** How would you reduce LLM hallucination in a production system?

**Q13.** What is cosine similarity and why is it used for embedding search?

**Q14.** Explain temperature and top-p sampling. How do they affect LLM output?

**Q15.** What is a vector database and how is it different from a SQL database?

**Q16.** Describe the difference between supervised learning, unsupervised learning, and reinforcement learning.

---

## Tier 3: Senior Level

These questions appear in senior/staff engineer interviews.

**Q17.** You're building a RAG system for a company with 10 million documents. What architectural challenges do you anticipate?

**Q18.** Explain the trade-offs between using GPT-4o vs Llama 3.1 70B (local) in a production system.

**Q19.** How would you design an evaluation system for an LLM-powered application?

**Q20.** Explain prompt injection. How would you defend against it?

---

## Tier 4: Scenario-Based

**Q21.** "Our AI assistant is giving wrong answers. Walk me through how you'd debug this."

**Q22.** "The CEO wants to add AI to our customer support system. What questions would you ask before starting?"

**Q23.** "Our RAG system's retrieval quality is poor — users say the answers are off-topic. What could cause this and how would you fix it?"

**Q24.** "We're spending $50,000/month on LLM API calls. How would you reduce costs without killing quality?"

## Behavioral Questions

**Q25.** Tell me about a complex system you built. What was the hardest part?

**Q26.** How do you stay current with AI developments? (It changes fast.)

**Q27.** Describe a time when you had to explain a technical concept to a non-technical stakeholder.

**Q28.** What's your approach to testing systems that don't have deterministic outputs?
