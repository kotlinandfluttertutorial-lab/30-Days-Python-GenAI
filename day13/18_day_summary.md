# Day 13 — Day Summary: NLP Fundamentals

## What You Covered
Tokenization (BPE), TF-IDF, word embeddings, sentence embeddings, stop words, lemmatization, and a classical text classification pipeline.

## Key Takeaways
1. Modern LLMs use BPE subword tokenization — not word splitting
2. TF-IDF is still used in hybrid search (BM25 + vector)
3. Sentence Transformers produce contextual embeddings (semantically aware)
4. Semantic similarity is NOT the same as word overlap
5. Classical NLP (TF-IDF + LR) still works well for simple classification with limited data
