# Day 16 — Day Summary: Prompt Engineering

## What You Built
Prompt Engineering Toolkit: zero-shot, few-shot, chain-of-thought, JSON extraction, RAG prompts, injection detection, prompt versioning system.

## Key Takeaways
1. The prompt is code — it determines behavior as much as Python logic
2. Zero-shot first; add examples only when format is wrong or accuracy is low
3. CoT adds reasoning power at the cost of tokens
4. Structured output requires stripping markdown fences before JSON parsing
5. Injection defense requires both input validation AND structural separation
