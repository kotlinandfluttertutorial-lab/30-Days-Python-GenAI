# Day 05 — Concepts
## Statistics + Data Analysis

The content for Day 05 statistics concepts is in `07_code/01_statistics_analysis.py` which demonstrates all concepts with working code. The core topics covered are:

1. **Normal Distribution** — Mean, std, percentiles for evaluation scores
2. **IQR Outlier Detection** — Q1-1.5×IQR, Q3+1.5×IQR bounds
3. **Correlation Analysis** — Pearson correlation matrix for features
4. **Skewed Distributions** — Log-normal for latency/word count
5. **Feature Engineering** — Composite scores, log transforms, percentile ranks
6. **Sampling** — Stratified sampling for balanced evaluation datasets

See `07_code/01_statistics_analysis.py` for full runnable implementation.
See `02_concepts.md` in the day folder for the complete written concepts (this file).
