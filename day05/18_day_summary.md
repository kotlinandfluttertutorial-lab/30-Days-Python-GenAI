# Day 05 — Day Summary: Statistics + Data Analysis

## What You Covered
Distributions, outlier detection, correlation analysis, and feature engineering — the statistical foundation for evaluating AI systems and preparing ML datasets.

## Key Takeaways
1. Normal distribution: ±2 std covers 95% — use to flag anomalies
2. IQR outlier detection is more robust than z-score for skewed data
3. Correlation matrix identifies which features predict quality
4. Log transform handles right-skewed features (latency, word count)
5. Statistical analysis of RAG evaluations reveals system failure patterns
