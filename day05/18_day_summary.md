# Day 05 — Day Summary: Statistics + Data Analysis

## What You Covered
Distributions (normal, log-normal), IQR outlier detection, Pearson correlation, feature engineering (log transforms, percentile ranks, composite scores), sampling strategies.

## Key Takeaways
1. Normal distribution: ±2 std = 95.4% — foundation for anomaly detection
2. IQR outlier detection is more robust than z-score for skewed data
3. Correlation matrix identifies which features predict quality metrics
4. Log transform: normalize right-skewed features (latency, word count)
5. In RAG evaluation: low-score outliers reveal system failures — investigate them
