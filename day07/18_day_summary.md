# Day 07 — Day Summary: Machine Learning Fundamentals

## What You Covered
Core ML algorithms (Linear/Logistic Regression, Decision Trees, Random Forest, KNN, K-Means), algorithm selection, feature engineering with sklearn, and a basic FastAPI ML prediction API.

## Key Takeaways
1. Random Forest is usually the best first choice for production ML
2. Always compare against a baseline before claiming improvement
3. Pipeline() wraps preprocessing + model to prevent data leakage
4. Feature importance from Random Forest guides feature engineering
5. The train/val/test workflow applies to every ML experiment

## Tomorrow: Day 08 — ML Evaluation
Every metric you need: accuracy, precision, recall, F1, ROC-AUC, cross-validation, hyperparameter tuning.
