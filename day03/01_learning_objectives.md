# Day 03 — Learning Objectives
## Python Engineering + NumPy + Pandas

---

## What You Will Accomplish Today

By end of Day 3, you can engineer clean data pipelines and use NumPy/Pandas — the data layer under every ML and AI system.

### Knowledge Objectives
1. Write professional OOP with inheritance, composition, and abstract classes
2. Use `@property`, `@classmethod`, `@staticmethod` correctly
3. Understand NumPy arrays vs Python lists — when each applies
4. Use Pandas DataFrames for data exploration and cleaning
5. Apply feature engineering patterns used in ML prep
6. Implement configuration management with environment variables
7. Write structured logging for AI applications

### Skill Objectives
1. Build a reusable base class for AI pipeline components
2. Load and clean a CSV dataset using Pandas
3. Compute statistics relevant to ML (mean, std, correlation, outliers)
4. Create features from raw data for ML models
5. Implement a train/validation/test split

### Project: AI Dataset Analyzer
A CLI tool that:
- Loads any CSV/JSON dataset
- Profiles the data (missing values, types, distributions)
- Cleans and prepares it
- Creates basic features
- Splits into train/val/test
- Exports a ready-to-train dataset
