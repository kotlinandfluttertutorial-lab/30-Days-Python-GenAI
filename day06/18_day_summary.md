# Day 06 — Day Summary: ML Mathematics

## What You Covered
Loss functions (MSE, cross-entropy), gradient descent from scratch, learning rate effects, overfitting/underfitting, bias-variance tradeoff, and regularization.

## Key Takeaways
1. Loss function = objective to minimize during training
2. Gradient descent: move parameters opposite to gradient direction
3. Cross-entropy is LLM's pretraining loss — predicts next token probability
4. Overfitting = good train, bad val; underfitting = bad both
5. Regularization (L1/L2/Dropout) prevents overfitting
