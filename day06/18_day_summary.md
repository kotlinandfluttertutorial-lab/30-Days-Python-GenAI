# Day 06 — Day Summary: ML Mathematics

## What You Covered
Loss functions (MSE, cross-entropy), gradient descent from scratch (linear + logistic regression), learning rate effects, overfitting/underfitting demonstration, regularization (L1, L2, dropout).

## Key Takeaways
1. Loss function = what training minimizes; choose based on task
2. Gradient descent: θ = θ - lr × ∂L/∂θ — move parameters against gradient
3. Cross-entropy is LLM's pretraining loss — predicts next token probability
4. Overfitting: great train, poor test — fix with regularization or more data
5. LLM fine-tuning uses lr=1e-5 (tiny) to avoid destroying pretrained knowledge

Mathematical foundations complete. Tomorrow begins classical ML — all the math becomes algorithms.
